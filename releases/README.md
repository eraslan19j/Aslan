# Releases — APK arşivi

Bu klasördeki `istanbul-streets-latest-debug.apk` **her etiketli sürümde otomatik güncellenir**
(`.github/workflows/android.yml` içindeki "Commit the working APK into the repository" adımı).

- Telefonuna kurmak için: dosyayı indir → dokunarak kur → "Bilinmeyen kaynaklara izin ver".
- Eski sürümler: `git log -- releases/` veya GitHub Releases sayfası.
- Her sürümün kendi APK'sı ayrıca <https://github.com/eraslan19j/Aslan/releases> altında durur.
